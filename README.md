## Paid Customization Scope

The paid package can produce:

- one customized static HTML page,
- one service niche,
- up to five service blocks,
- basic FAQ or proof section if buyer provides facts,
- contact/quote copy,
- mobile styling,
- handoff notes.

Not included: hosting setup unless separately scoped, payment processing, logo design, custom photography, legal/medical/financial claims, or publishing under a business name without owner approval.
